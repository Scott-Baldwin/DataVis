# DataVis
Data visualization practice using the latest new tools.

# Setup
## Install with UV (recommended)
This project uses [UV](https://github.com/astral-sh/uv) as a package manager. Check out the UV [docs](https://docs.astral.sh/uv/) and [GitHub](https://github.com/astral-sh/uv) for more info. **There are 2 easy ways to install uv from a terminal:**

### Standalone UV Installer from Astral (Recommended):
On Windows:
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```
On macOS and Linux:
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```
If installed via the standalone installer above, uv can update itself to the latest version. It's a good idea to run this occasionally:
```
uv self update
```

### *Install UV with pipx (Optional)*
Useful if the standalone installer is blocked - can happen in enterprise environments

*Using a virtual environment is recommended but not necessary here.*
```
pip install pipx
pipx install uv
```





## Install dependencies 
### With UV (Recommended)
Install default project packages:
```
uv sync
```
Install with optional development packages:
```
uv sync --dev
```

### *With PIP (Optional)*
A pip-compatible list of requirements can be used to install required packages. A [requirements.txt](requirements.txt) file can be auto-generated by running this command in a terminal:
```
uv pip compile pyproject.toml -o requirements.txt
```
Install packages in the text file using this command:
```
pip install -r requirements.txt
```
Or packages can be installed on by one-by-one using the [pyproject.toml](pyproject.toml) file as a guide.

*Pip is not recommended for development*, but can be useful for quick tests and debugging. **Development within a virtual environment (venv) is strongly suggested**, and is handled automatically by uv.

# Run the project:
```
uv run src/main.py
```

# Data
Example meteorological data was downloaded from the [NSRDB](https://nsrdb.nrel.gov/data-viewer).

# Packages
Project dependencies are tracked in the [pyproject.toml](pyproject.toml) file, and their function is summarized below:

### Core Functions
 - [Polars](https://github.com/pola-rs/polars) - for data operations
 - [PsychroLib](https://github.com/psychrometrics/psychrolib) - for psychrometric calculations on meteorological data
 - [Matplotlib](https://matplotlib.org/) - for plotting

### Development Tools
 - [ipykernel](https://github.com/ipython/ipykernel) - for interactive sessions and jupyter notebooks
 - [Pandas](https://pandas.pydata.org/) & [PyArrow](https://arrow.apache.org/docs/python/index.html) - for viewing data with the [Data Wrangler](https://marketplace.visualstudio.com/items?itemName=ms-toolsai.datawrangler) vscode extension
 - [Ruff](https://docs.astral.sh/ruff/) - for automatic code formatting
